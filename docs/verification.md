# 검증 기록 · 2026-11-20

검증 환경은 macOS arm64, Flutter 3.50.1 / Dart 3.13 계열, JDK 21.0.13.1, Maven 3.9.11입니다. SDK는 시스템 전역 설정 없이 `/tmp/flutter-tutorial-tools`에 다운로드하여 사용했습니다. 임시 폴더가 정리되면 별도 설치가 필요합니다.

## 확인한 결과

- Spring Boot API 통합테스트 2개 통과: 생성/조회/수정/삭제, 잘못된 HTTPS URL 및 장소 ID 거부, 데모 주소 검색, 좌표 만료 삭제 및 갱신.
- 실행 가능한 Spring Boot jar 패키징 성공.
- `scripts/check_persistence.py` 통과: 임시 파일 H2에 생성 → 실제 JVM 종료 → 새 JVM 시작 → 동일 UUID/제목/태그 복원 → 삭제 확인.
- `flutter analyze`: No issues found.
- `flutter test`: 초기 3개 통과. 이후 모바일 지도 탭 확인을 추가하여 48px 하단 overflow를 발견했고 안내 패널을 스크롤 가능하게 수정했습니다. 수정 후 분석/테스트 결과를 아래에 기록합니다.
- `flutter build web --release`: 이전 실행 성공. 기본 API 모드 산출물은 `frontend/build/web`에 있습니다. 이후 Material 패키지 전환 및 모바일 안내 패널 수정 후 웹 재빌드는 수행하지 않았으므로 최종 소스로 사용하려면 README 명령으로 다시 빌드하세요.
- 로컬 API 실행 후 `/api/status`가 `{"geocodingMode":"demo","status":"ok"}`로 응답한 것을 확인했습니다.

## 검증 범위의 한계

- Google API 키가 제공되지 않아 실제 Geocoding 응답, 지도 렌더링, API 키 제한/과금은 검증하지 않았습니다. 키 없는 기본 실행의 주소 검색은 고정 후보를 사용하는 명시적 데모입니다.
- Android/iOS 소스와 설정은 생성했지만 네이티브 빌드·실기기 실행은 검증하지 않았습니다.
- PostgreSQL 프로필과 Docker Compose는 제공했지만 실행하지 않았습니다.
- 실제 브라우저 화면 확인은 완료하지 못했습니다. 하위 에이전트의 in-app browser 표시가 지원되지 않았고, native Chrome 접근 호출이 반환되지 않아 중단했습니다. UI 검증 결과는 Flutter widget 테스트 기준입니다.
- 로컬 API 및 웹 서버 실행을 시도했으나 최종 전달 시 프로세스 유지 여부는 보장하지 않습니다. 루트 README의 명령으로 다시 실행하세요.

## 최종 수정 후 재검증

`map_panel.dart`의 안내 영역에 `SingleChildScrollView`를 적용해 좁은 모바일 화면에서도 설명과 고정 카드가 세로 공간을 넘치지 않도록 했습니다. 수정 후 `flutter analyze`는 **No issues found**, `flutter test`는 모바일 지도 탭 검증을 포함해 **3개 모두 통과**했습니다. 추가 브라우저 호출이나 웹 재빌드는 수행하지 않았습니다.

## 디자인 개선 검증 · 2026-11-21

- 작은 76px 음식 썸네일, 한 줄 메모, 태그를 쓰는 공통 리스트/지도 카드로 변경했습니다. 목록 항목은 상세 바텀시트, 우측 지도 아이콘은 지도 선택으로 연결됩니다.
- 모바일 목록/지도 탭과 데스크톱 410px 목록 + 지도 배치를 유지합니다. 지도 상단에는 불필요한 카테고리 탭을 추가하지 않았습니다.
- 지도에는 가게명 라벨과 선택 상태, 하단 미리보기를 표시합니다. Google 기본 정보창이 카드와 중복해서 뜨지 않도록 마커 탭을 직접 처리합니다. 웹 지도 위의 검색창과 카드에는 pointer_interceptor를 적용했습니다.
- 사진 URL을 선택 입력으로 추가하고 API/DB/메모리 저장소까지 연결했습니다. 누락된 기존 필드는 빈 값으로 읽고 이미지 로드 실패는 기본 음식 아이콘으로 처리합니다. 실행 중인 이전 백엔드는 다시 시작해야 새 필드를 저장합니다.
- Noto Sans KR 폰트를 앱에 포함해 웹의 지연 폰트 로딩으로 필터 글자가 잘리던 현상을 해결했습니다. 라이선스는 `frontend/assets/fonts/OFL.txt`에 있습니다.
- Flutter widget/store 테스트 4개 통과: 모바일 검색/폼 검증, 데스크톱 지도 선택, 320×568 화면에서 탭 전환 후 검색 유지와 상세 시트, 저장소 CRUD/필터.
- Spring API 통합테스트 3개 통과: 기존 CRUD/좌표 만료 외에 사진 URL 저장·조회·삭제 및 잘못된 URL 거부 포함. 테스트 DB는 메모리 H2입니다.
- 정적 분석과 release 웹 빌드 통과. 브라우저에서 390×844 모바일 사진 목록과 실제 Google 지도/가게명 라벨/선택 카드 표시를 확인했습니다.
- Android/iOS 네이티브 빌드는 이번 변경에서 실행하지 않았습니다. 데모 사진은 실제 저장한 가게의 사진이 아닌 예시입니다.
